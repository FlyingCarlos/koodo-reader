# 原生 PDF 阅读器的翻译扩展

## 集成边界

`Reader` 保留整个原阅读器组件树；`TranslationPanel` 只显示任务状态和开关。不得再通过提前 `return` 一个新阅读器隐藏原生功能。

`Viewer` 在创建原生 `PdfRender` 后调用 `attachPdfTranslation`。适配器不修改打包的 Kookit 库，也不替换原生目录、搜索、进度、PageWidget、PDF canvas、文本层、链接和批注画布。原文保持 PDF 版式，右侧译文使用同一原生页面文档；原生文档选区监听器和 PopupMenu/PopupBox 因而处理两侧的选择。

双语模式的 `comparisonViewport` 使用当前可用宽度，为锁定的目录、设置或右侧停靠面板预留空间；`Viewer` 和原生仿真背景共用该区域。原 PDF 等比适配左栏可用宽度，不直接把原生高度适配结果再减半。canvas、文本层、链接和批注继续共用原生坐标体系。滚动模式按 PDF 物理页组织两栏，页高容纳两侧内容；原阅读器的滚动、渲染与位置记录继续负责翻页。翻页模式保留原生导航，过长的单页译文可在右侧滚动。

桌面中文段落先匹配原生文本层的文字，再用来源坐标选择附近的匹配；找不到文字时回退到来源区块范围。字号读取 PDF 设备像素变换后的实际显示值，中文使用对应英文的 94%，正文至少 14px、图注至少 12px；行距参考英文行距，并限制在 1.45–1.65。段落起点按来源位置安排，空间不足时最多缩至初始字号的 88%，且仍遵守上述字号下限。若译文仍过长，顺延后续中文区块并增高页面，不裁切译文，也不移动原 PDF 英文文本层、画布或批注。段落对齐是尽力匹配，不是逐行复刻或所有 PDF 的保证。

滚动模式下，原生阅读区域宽度小于 560px 时，在同一页面 iframe 内改为原 PDF 在上、中文在下；组合页高包含两者。原生页面容器以 720px × 当前请求缩放比例安排宽度，PDF 等比适配其中，使用原生横向滚动查看，现有缩放控件仍可调整大小。中文按来源顺序排版，宽度适配可见区域并跟随横向滚动保持可见；此模式不做段落起点的左右对齐。恢复宽屏后回到左右布局。

## 批注兼容

英文 `getHighlightCoords`、`createOneNote` 和 `renderHighlighters` 直接委托原生实现。中文选区保存为 `koodo-pdf-translation-v1`，包含书籍提取指纹、原 PDF 页索引、段落 ID、文字偏移与引文。恢复时同时校验指纹和引文，避免排版或译文变化后错位。两种范围分开渲染，但均使用原生笔记数据库、编辑器、标签和删除流程。

中文笔记的 CFI 增加 `localTranslation` 锚点；原生跳转先到源 PDF 页，再定位译文。若当前关闭双语，会启用同一 Viewer 的双语扩展。不得把中文屏幕像素写成英文 PDF 坐标，或覆盖既有英文笔记。

## 生命周期

原生 PdfRender 会在长期存在的 `#page-area` 上添加滚动监听器。开关双语、缩放或重建时，适配器清理旧监听器、轮询和 ResizeObserver，并阻止旧渲染器延迟回调覆盖新页码。DOM 回归测试覆盖这个问题。`removeContent` 仍由原生实现清空内容。

任务与译文使用原有 `/api/translation/` 和私有状态目录，本次集成不重译已完成的序言与第 0 章。译文轮询只更新挂载页面，并在用户选中中文时延后替换，避免破坏选区。

## 验证与限制

- 12 项前端回归测试（适配层 7 项、对照布局 4 项、进度组件 1 项）：原生方法委托与批注过滤、跨段中文文字锚点、引文变化保护、监听器和延迟回调清理、窄屏/宽屏适配、译文异步增高时的可视页位置保持、可用宽度与固定面板预留、文字匹配、原生字号及行距测量，以及进度组件绑定新渲染器并忽略旧实例事件。
- Edge 实际验证：英文与中文原生选中菜单；中文笔记保存、刷新恢复、再次打开和删除；英文原生笔记在双语开关前后的坐标比例恢复、重新编辑和删除；原生页码与目录跳转，以及“返回原处”。测试创建的两侧笔记已清理。
- 本轮桌面对照检查使用《Inference Engineering》PDF 实际第 19 页：在 1874px 浏览器宽度下，英文实测字号约 18.67px、对应中文约 17.55px；11 个来源区块均匹配并按来源起点对齐。这是该页的检查结果，不代表全书或其他 PDF 均能同样对齐。
- PDF 文字重排模式仍可使用，其双语渲染尚未接入；当前扩展面向原 PDF 模式。
- 图中文字不翻译，复杂表格、公式及字体提取限制沿用后台说明。全书正文搜索仍搜索原文。

本次验证不等于穷举所有 PDF、操作系统或原生功能组合；遇到回归应修复适配层并增加用例，而不是复制一份原生功能到另一个阅读器。
