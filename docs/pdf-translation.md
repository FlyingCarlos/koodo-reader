# 原生 PDF 阅读器的翻译扩展

## 集成边界

`Reader` 保留整个原阅读器组件树；`TranslationPanel` 只显示任务状态和开关。不得再通过提前 `return` 一个新阅读器隐藏原生功能。

`Viewer` 在创建原生 `PdfRender` 后调用 `attachPdfTranslation`。适配器不修改打包的 Kookit 库，也不替换原生目录、搜索、进度、PageWidget、PDF canvas、文本层、链接和批注画布。原文保持 PDF 版式，右侧译文使用同一原生页面文档；原生文档选区监听器和 PopupMenu/PopupBox 因而处理两侧的选择。

双语模式的 `comparisonViewport` 使用当前可用宽度，为锁定的目录、设置或右侧停靠面板预留空间；`Viewer` 和原生仿真背景共用该区域。原 PDF 等比适配左栏可用宽度，不直接把原生高度适配结果再减半。canvas、文本层、链接和批注继续共用原生坐标体系。滚动模式按 PDF 物理页组织两栏，页高容纳两侧内容；原阅读器的滚动、渲染与位置记录继续负责翻页。翻页模式保留原生导航，过长的单页译文可在右侧滚动。

桌面中文段落先匹配原生文本层的文字，再用来源坐标选择附近的匹配；找不到文字时回退到来源区块范围。字号参考源页正文主字号及实际 PDF 显示比例；没有格式元数据时从原生文字层估计正文主字号。同一页、同一缩放下，正文、列表和表格使用统一字号，取英文正文的 94%，且至少 14px，行距为 1.5。标题至少为正文的 1.22 倍，图注为正文的 83% 且至少 12px。不逐段缩小以挤入来源高度。段落起点按来源位置安排；译文过长时顺延后续中文区块并增高页面，不裁切译文，也不移动原 PDF 英文文本层、画布或批注。段落对齐是尽力匹配，不是逐行复刻或所有 PDF 的保证。

滚动模式下，原生阅读区域宽度小于 560px 时，在同一页面 iframe 内改为原 PDF 在上、中文在下；组合页高包含两者。原生页面容器以 720px × 当前请求缩放比例安排宽度，PDF 等比适配其中，使用原生横向滚动查看，现有缩放控件仍可调整大小。中文按来源顺序排版，宽度适配可见区域并跟随横向滚动保持可见；原生滚动条出现后会重新测量可见宽度，此模式不做段落起点的左右对齐。恢复宽屏后回到左右布局。

## 已有译文的格式恢复

已翻译页面的面板提供“恢复本页格式”，逐页手动执行，不自动重译正文或整本书。后台从原 PDF 提取加粗、斜体、等宽/衬线文字和表格几何，保存为书籍目录中的附加 `source-format-v1.json`；每页的译文格式映射保存为 `page-format-NNNN.json`。原 `document.json`、书籍 ID、提取版本、来源区块 ID 和源 PDF 均不变。

格式 Agent 使用本应用自己的订阅授权及 OpenAI Agents SDK，只从已有中文中返回精确引文及其出现次数。程序验证来源标识、允许的区块、完整单元格集合与文字覆盖，拒绝改写、遗漏、重叠或引用其他单元格的区块，再转换为 UTF-16 偏移。来源格式与现有译文共同构成指纹；章节读取时若指纹变化，旧格式返回 `pending`，不把旧格式套到新文字上。完整结果可直接复用；映射尚未恢复或表格片段未完整覆盖文字时，前端回退到普通译文。

前端生成语义 DOM：加粗为 `strong`，斜体为 `em`，等宽为 `code`，衬线为带字体样式的片段；表格使用 `table`、`th`、`td`，保持来源行列和跨行跨列信息。模型不生成 HTML 或新增文字。来源相邻单行正文可合为一个视觉段落，各片段仍保留原区块 ID 和精确译文；不改写或增补正文来修正原提取方式。

格式任务与章节翻译共享生产 worker 的 `operation_lock` 和私有目录 `worker.lock`。调用模型前先持久化格式任务指针；恢复可复用已完成的格式阶段，不再发起模型请求。不得另起一个生产 worker 访问同一状态目录。响应尚未持久化即崩溃时仍可能重发该阶段，不承诺计费层面恰好一次。

## 目录条目与印刷页码

来源目录元数据 `toc_entries` 由原区块文字和坐标派生：同页至少三条具有重复点状引导线、共同页码
右边缘的条目才识别为目录，支持数字和罗马数字。记录来源区块 ID、标题、印刷页码、相对缩进及
标题/页码加粗。每次来源格式读取也为旧缓存页派生这些信息，不修改原 `document.json`。目录元数据
不参与已有格式指纹或格式 Agent 输入，已缓存的加粗及表格映射可继续复用；前端排除包含目录
区块的旧正文合并组，防止多个条目再次粘成一段。修正已有目录显示不需要模型请求。

中文条目使用标题、引导线、页码三个连续的 UTF-16 片段，保留缓存中文的全部字符、原区块 ID 和
偏移。字面点线或制表符保留为零字号文字，由 CSS 点状边框随剩余宽度伸缩；标题可换行，末尾
页码列宽 `3ch`、右对齐并使用等宽数字。缩进随源页比例缩放，最多占中文可用宽度的 20%；标题
与页码保留各自来源加粗信息。宽窄屏都按独立条目排列，长标题换行后页码位于该条目末行右侧。
印刷页码不换算为 PDF 物理页索引，例如印刷 9 仍显示 9，不改成物理第 11 页。若译文末尾无法
匹配来源的印刷页码，回退普通译文。旧笔记可跨标题、原字面点线和页码恢复，无需迁移数据库。

## 多段合批与恢复

原章节工作流已按最多 12 段、6,000 源字符合批，输入 schema 最多 20 段，并非逐目录行请求。
当前 `BatchBudget` 默认最多 96 段、20,000 源字符，同时用 UTF-8 字节估算输入、输出和审校上下文：
输入预算 6,000 tokens（包含共享提示、schema、工具与术语的 1,500 tokens 预留），输出预算
6,000 tokens，审校预算 14,000 tokens。估算不是模型专用 tokenizer，也不保证实际模型上下文上限；
不可再分的旧区块超过软估算时独占一批，仍受 20,000 源字符输入硬限制。

识别为目录的条目仅在模型输入中去掉重复字面引导线，改为 `标题\t印刷页码`，保护最后的制表符及
页码。已有受保护字面量无法保留时使用原文。原提取文字、来源 ID、译文缓存身份和已创建作业的
输入不变。新批次以 `source_mode=compact-toc-v1` 持久化此策略；恢复时仅重新合并连续且尚未创建
`job_id` 的批次，已经开始或失败待重试的作业继续使用原输入和指纹。

每批仍执行翻译、独立审校及必要修订；工具回合会产生额外模型请求，工作流批次并不等于请求数。
面板的 `batch_count`、`completed_batches` 显示批次进度，与已审校段落进度分别计算。

## 批注兼容

英文 `getHighlightCoords`、`createOneNote` 和 `renderHighlighters` 直接委托原生实现。中文选区保存为 `koodo-pdf-translation-v1`，包含书籍提取指纹、原 PDF 页索引、段落 ID、文字偏移与引文。恢复时同时校验书籍身份和引文，避免译文变化后错位。每个格式片段携带 `data-translation-start` 的 UTF-16 起始偏移；同一旧区块分布到多个表格单元格后，旧 `koodo-pdf-translation-v1` 范围仍能跨片段恢复，无需笔记数据库迁移。两种范围分开渲染，但均使用原生笔记数据库、编辑器、标签和删除流程。

中文笔记的 CFI 增加 `localTranslation` 锚点；原生跳转先到源 PDF 页，再定位译文。若当前关闭双语，会启用同一 Viewer 的双语扩展。不得把中文屏幕像素写成英文 PDF 坐标，或覆盖既有英文笔记。

## 生命周期

原生 PdfRender 会在长期存在的 `#page-area` 上添加滚动监听器。开关双语、缩放或重建时，适配器清理旧监听器、轮询和 ResizeObserver，并阻止旧渲染器延迟回调覆盖新页码。DOM 回归测试覆盖这个问题。`removeContent` 仍由原生实现清空内容。

任务与译文使用原有 `/api/translation/` 和私有状态目录，格式恢复只添加展示信息，不重译现有正文，也不修改章节任务。译文轮询只更新挂载页面，并在用户选中中文时延后替换，避免破坏选区。

- 前一轮格式恢复验证的 17 项前端和 28 项后台测试通过，TypeScript 检查与生产构建通过。覆盖原生方法委托、批注文字锚点、引文变化保护、生命周期清理、宽窄屏布局、统一正文字号、样式与表格片段、UTF-16 偏移、旧笔记跨单元格恢复，以及格式映射验证、指纹失效和已完成阶段复用。
- Edge 原有集成检查涵盖两侧原生选中菜单、中文笔记保存/刷新/编辑/删除、英文批注坐标恢复、原生页码与目录跳转、“返回原处”及双语开关。
- 前一轮格式恢复检查《Inference Engineering》PDF 实际第 27–29 页，覆盖 1874×930、1440×900 和 390×844 视口。第 27 页正文实测统一约 17.4389px，第 28 页加粗标签与正文同字号，第 29 页呈现两列四行、八个单元格的真实表格。斜体、等宽、衬线已有实现与测试，这三页主要验证加粗，不宣称其包含实际斜体样例。
- 在升级前的普通中文表头创建笔记，恢复格式后同一笔记可在实际表格内定位并打开原生编辑器，原评论保留；英文与中文表格两侧的原生菜单和编辑器均可见。验证创建的笔记已删除，未改写用户既有笔记。
