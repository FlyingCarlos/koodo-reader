# PDF 内容白底与阅读主题

## 使用与保存

在原生 PDF 右侧“阅读选项”中，“保留PDF中的原始背景”下方的“隐藏 PDF 内容白底”默认关闭。
开启后隐藏页面开头的大面积纯白底板，让现有阅读主题透出；关闭后恢复原生渲染。
说明文字明确标注“仅当前书”，图片和表格保留原样。该选项只出现在原版式 PDF 中。

设置通过 `ConfigService` 的 `pdfHideContentBackground:<bookKey>` 保存 `yes` 或 `no`，
不受通用的书籍独立样式开关影响。切换后保存设置并调用原阅读器的重新渲染方法，渲染期间禁用按钮。
若刷新失败，设置仍保留，界面提示关闭并重新打开本书。按钮使用原生开关外观、主题和键盘焦点，
并提供 `role="switch"`、`aria-checked`、关联标签及说明。

## 渲染边界

`Viewer` 在创建原生 rendition 后，先调用 `attachPdfContentBackground`，再挂载已有双语适配器。
选项开启时，适配器包裹原生 `handleRenderPDFChapter` 与 `PDFPageProxy.render`，
仍返回同一个原生 `RenderTask`，保留其取消能力，并将页面初始背景设为透明。
它只在受支持的原生页面主 canvas 上过滤绘制操作，不扫描或替换白色像素。

`filterPdfPaperFills` 只跳过绘制顺序开头符合全部条件的底板：

- 不透明纯白，使用普通 `source-over` 合成，无滤镜、模糊或偏移阴影。
- 已知的闭合矩形路径或 `fillRect`；按当前变换换算后为轴对齐的四角矩形。
- 面积至少为 canvas 实际像素面积的 70%，并且上下左右分别延伸到距对应边缘 15% 以内。
- 出现在文字、图片、描边或其他不透明内容绘制之前。

非白色、小面积、半透明、曲线、多路径、未知路径及不符合整页底板条件的裁剪图形保留原样。
一旦绘制正文或其他内容，之后即使出现大面积白色也保留。因此图片自身白底、代码块、
表格单元格、提示框和后续插图的白色区域不会按像素消除。复杂页面可能仍有白底；
这不是对全部 PDF、所有裁剪和渲染组合的无损识别保证。

上下文绘制方法在渲染 Promise 完成、拒绝或同步抛错时恢复；移除内容时恢复包裹的页面与
rendition 方法，并阻止已销毁实例在异步取页后继续安装。原 PDF 字节、打包的 Kookit/PDF
运行库、页面尺寸、缩放和裁剪参数、文本层、链接、批注以及原生笔记和高亮方法均不改写。
该功能不涉及 Python 后台，也不创建翻译或模型请求。
